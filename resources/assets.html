VCC Package Listing

Add our repository to your VRChat Creator Companion to easily install and manage VRTon assets.

Instrucciones de Instalación

Los assets requieren tanto poyomi toon como vrcfury, estos deberían instalarse automáticamente al importar el paquete.

  1. Descarga el archivo .unitypackage
  2. Abre tu proyecto en Unity
  3. Importa con Assets → Import Package
  4. Sigue las instrucciones del README incluido

Todos los assets son compatibles con VRChat y han sido probados con las últimas versiones del SDK.

How to add this listing to your VCC

To add this listing to your VCC (VRChat Creator Companion), do the following:

  1. Open your VCC and go to Settings
  2. Click the "Packages" tab
  3. Click "Add Repository"
  4. In the field that appears - paste the url displayed above
  5. Click "Add"
  6. Check the repository info and click "I Understand"
  7. Go to any of your projects to see the packages from the newly added listing

You can read more about Package Listings on the VCC docs
